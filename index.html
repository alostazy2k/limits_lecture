Real Functions — Limits

Understanding limits through three functions

A limit describes what a function approaches near a point — not necessarily what happens at the point itself. The three cases below show why the limit can exist, why it can fail to exist, and a subtler way it can fail: a function that stays bounded yet never settles as x → 2.

01

A continuous function

For f(x) = x² − x + 1, watch a point travel along the curve toward x = 2 from the right and then from the left. Both approaches land on the same value, which is exactly why the two-sided limit exists.

02

A jump discontinuity

Now the curve is split at x = 2: f(x) = x+1 before it, f(x) = x−1 from it onward. The right-hand approach and the left-hand approach head toward different values — so no single number describes what the function does near that point.

03

Oscillation without decay

f(x) = sin(1/(x−2)) stays trapped between −1 and 1, but as x approaches 2 it oscillates faster and faster without ever calming down. Zooming in only reveals more oscillation, never convergence — a case where boundedness alone isn't enough for a limit to exist.
